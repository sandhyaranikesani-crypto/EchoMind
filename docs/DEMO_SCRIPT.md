# EchoMind — Demo Video Script (target: 75–90 seconds)

Goal: make the judge *feel* the problem, then watch memory make the agent
dramatically better in under 90 seconds. Memory is the star.

Setup before recording:
- App running, backend = "Hindsight server", brand = "EchoMind AI".
- Bank pre-seeded (sidebar → "Seed demo brand memory").
- Click "Reset demo view" so you start clean.

---

## 0:00–0:12 — The hook (the problem)
> "Every AI writing tool has amnesia. It'll happily suggest the same post you
> rejected last week, in a voice that isn't yours. Marketing teams reinvent the
> wheel every single day."

On screen: the hero header, then the **Dashboard** tab.

## 0:12–0:25 — The evidence
> "EchoMind starts from hard data. It sees we're starving our 'Engineering
> Culture & Leadership' pillar — 6.7% of output against a 20% target — while
> over-indexing on architecture."

On screen: hover the pillar table + bar chart; point at the gap and the
saturated pillar.

## 0:25–0:45 — Memory OFF vs ON (the core)
> "Here's the difference memory makes. On the left, a stateless tool: generic,
> no voice, fixed format. On the right, EchoMind with Hindsight memory."

On screen: **Recommendation** tab → *Generate*. Show the two columns side by
side. Read one line from the ON column's **angle** and point to the recalled
**guardrails** and **beliefs** chips. Point at the **conviction** bar and the
"+N from memory" badge.

## 0:45–1:05 — Watch it learn (the wow)
> "Now watch it learn. I reject this and tell it why."

On screen: **Watch it learn** tab → *Run learning simulation*.
> "One click: it recommended, I rejected with a critique, and it recommended
> again — recalling my feedback and *changing the actual plan*. The format
> switched, the angle adapted. That's Hindsight consolidating experience into
> behavior."

On screen: point at Before vs After — the "experiences recalled" count going
up, the "Memory changed the plan" badge, and the recalled critique chip.

## 1:05–1:18 — Proof it's real memory
> "This isn't a prompt trick. Every brand gets its own isolated Hindsight bank."

On screen: **Memory** tab → *Load memory ledger* (world facts / observations /
experiences). Switch brand to **Verdant Coffee Co.** → reload → totally
different brain. Say: "No cross-tenant leakage."

## 1:18–1:30 — The payoff + close
> "And it ships a deliverable — an on-brand draft — plus you can just ask it
> anything, answered from memory."

On screen: back on **Recommendation**, click *Generate post draft*; then
**Ask** tab, type "What should we avoid, and why?".
> "EchoMind: a content strategist that remembers, learns, and gets better every
> week. Built on Hindsight."

---

## B-roll / cutaway ideas
- The conviction bar filling as memory is added.
- The "Memory changed the plan: Carousel → Thread" badge.
- The chips lighting up in the causal audit sheet.

## Recording tips
- Pre-warm each tab once before recording (first Hindsight call is slower).
- Keep the critique short and punchy so the "after" is obviously different.
- If a live call lags, cut to the result; don't wait on camera.
